# 执行路由参考耗时

测试环境：Windows 测试机、每组 3 份生成的受保护示例文档；每次启动独立进程，包含启动、读取和保存。每项预热 1 次，再测 3 次，取中位数。速度倍数 = COM 耗时 ÷ 该路由耗时，COM 为 1x。

不同机器、文档复杂度、文件数量以及是否常驻运行会显著改变结果。Aspose 为未授权试用版，Word 只输出文本，与其他保格式路径工作量不等价。

- 旧式窗体 → Excel：com 14.103 秒（1.0x）；python 1.293 秒（10.9x）；rust 0.019 秒（731.7x）；aspose 1.486 秒（9.5x）。
- 旧式窗体 → Word：com 9.821 秒（1.0x）；rust 0.033 秒（294.0x）；aspose 1.920 秒（5.1x）。
- 内容控件 → Excel：com 12.469 秒（1.0x）；python 1.949 秒（6.4x）；rust 0.020 秒（613.2x）；aspose 1.431 秒（8.7x）。
- 内容控件 → Word：com 13.160 秒（1.0x）；rust 0.029 秒（454.2x）；aspose 1.846 秒（7.1x）。

openpyxl 仅支持 Excel 输出；自动路由按格式和配置选择，因此没有固定倍数。每次交互式执行结束后另显示实际执行耗时。
